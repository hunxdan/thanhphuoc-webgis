Thư mục này dùng để đặt file font tự host (tùy chọn):
  - Raleway-Variable.woff2
  - Inter-Variable.woff2

Nếu không có, website vẫn chạy bình thường và tự động dùng font hệ thống
tương đương (Segoe UI / Helvetica Neue / Arial) nhờ khai báo "font-display: swap"
và danh sách font dự phòng trong css/base.css. Đây KHÔNG phải lỗi.

Để dùng đúng font thiết kế, tải bản Variable Font (giấy phép OFL) tại
Google Fonts rồi đặt 2 file .woff2 vào đúng thư mục này với đúng tên ở trên.
